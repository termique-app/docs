The Termique mobile app is a companion to the desktop app. It uses the same account, API backend, and encryption. Sign in, unlock with your master password, and your synced hosts, groups, snippets, and SSH keys are on your phone.

## Install

| Platform | Link |
|----------|------|
| iOS | [App Store](https://apps.apple.com/us/app/termique/id6773997253) |
| Android | [Google Play](https://play.google.com/store/apps/details?id=app.termique.mobile) |

## Sign in and unlock

Sign in with the same account you use on the desktop, then enter your master password. Credentials encrypted on the desktop decrypt on mobile and the reverse, because both use the same master password and DEK. Only synced hosts appear on mobile. A host kept only on your computer stays there.

After 5 wrong master password attempts, unlocking is blocked for 5 minutes.

## What you can do on mobile

The app has four tabs: **Hosts**, **Snippets**, **Keys**, and **Settings**.

### Hosts

- Add, edit, and delete hosts, including a jump host.
- Connect in a full SSH terminal. Open several sessions and switch between them.
- In a session, use **Run snippet…**, **Find in scrollback**, and **Files (SFTP)**. Pasting more than one line asks first.
- Browse files over SFTP: download, upload, create folders, rename, and delete.
- Open **Groups** from the Hosts menu to create, edit, and view groups. A group's page lists its hosts. Add hosts with **Add hosts**, or remove one. Removing a host from a group does not delete the host.
- On a host's page, set a **Startup snippet**: a snippet typed into the terminal as soon as a session connects. This setting is stored on the phone and is not synced.

### Snippets and SSH keys

- Create, edit, and run snippets, and browse the snippet **Marketplace**.
- Generate a new SSH key (Ed25519, ECDSA, or RSA) or import an existing one (OpenSSH, PKCS#1 RSA, or EC).

### AI assistant

Open **AI assistant** from a host's page or from a terminal session. The assistant proposes commands and asks **Run this command?** before each one. It uses the hosted provider and shares the daily prompt limit with the desktop. See [AI assistant](/ai-assistant).

In **Settings** > **AI assistant**:

- **Auto-run safe commands**: read-only, low-risk commands run without asking. Others still ask. Off by default, and set per device.
- **Memory**: see, add, and delete what the assistant remembers. Requires Pro.

### Monitoring and alerts

You install the monitoring agent from the desktop app. On mobile you can:

- Open **Monitoring** from the Hosts menu, or from **Settings** > **Activity** > **Monitoring**, to see every monitored host.
- Open a host's metrics: live CPU, memory, and disk, and charts for `1h` to `1y`. Ranges beyond what your plan keeps show an upgrade notice.
- Open **Manage alerts** on a host you own to add, edit, enable, or delete [alert rules](/monitoring#alert-rules).

See [Monitoring](/monitoring).

### Activity and investigations

- **Command logs**: a host's logged sessions, from its page. Requires Pro.
- **Settings** > **Activity** > **Command logs**: sessions across all your hosts, filtered by **All**, **Mine**, **Teammates**, or **Sudo**. Requires Pro. See [Command logs](/command-logs).
- **Settings** > **Activity** > **Investigations**: reports from [incident investigations](/incident-investigation) you ran on the desktop. You can read them on mobile but not start one.

### Sharing

Open **Settings** > **Sharing & team** to accept and manage share invites, under **Received**, **Sent**, and **Team**. Sharing a host from mobile requires Pro. See [Sharing](/sharing).

## Security settings

In **Settings** > **Security**:

- **Biometric unlock**: unlock with Face ID, Touch ID, or your device's biometrics instead of typing the master password.
- **Auto-lock**: how long the app can stay in the background before it locks. Choose **Immediately**, or after 1, 2, 5, or 15 minutes, or 1 hour. The default is 2 minutes.
- **Log commands on new hosts**: the default command logging setting for hosts you add. Existing hosts keep their own setting. Requires Pro.
- **Master password**: change it. Enter **Current password**, **New password** (8 or more characters), and **Confirm new password**, then tap **Change password**. Your other devices unlock with the new password too. Termique cannot recover it if you forget it.

## Devices

**Settings** > **Devices** lists the computers and phones signed in to your account, most recent first.

- Removing a device only takes it off the list. It comes back the next time it opens Termique.
- If you lose a device, tap **Sign out everywhere**. Every device and browser signed in to your account is signed out, this phone too, and you sign in again.

## Push notifications

On [Pro](/plans), monitoring alerts arrive as push notifications, even when the desktop app is closed. A notification names the host and the metric, for example `CPU threshold exceeded`. Tap it to open that host's alert rules.

Notifications need to be allowed for Termique in your phone's system settings.

## Sync

Mobile uses the same API backend as the desktop. Changes to hosts, groups, snippets, and SSH keys on one device appear on the other. Settings on the phone, such as **Auto-lock**, **Auto-run safe commands**, and startup snippets, apply only to that phone.
